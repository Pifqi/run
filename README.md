# Interval Running Timer

A mobile-first, web-based interval timer designed for running and sprinting. 

## Features
- **Modern UI**: Dark mode interface with vibrant green (Run) and orange (Sprint) accents.
- **Interval Cycle**: Automatically cycles between 60-second Run phases and 15-second Sprint phases.
- **Audio & Haptic Feedback**: Emits a beep and vibrates the phone when transitioning between phases.
- **Progress Tracking**: Tracks the total number of completed cycles and overall running duration.
- **No Dependencies**: Built entirely with Vanilla HTML, CSS, and JavaScript.

## How to Deploy
This project is a static website. You can deploy it instantly on platforms like **Netlify**, **Vercel**, or **GitHub Pages**.

1. Upload these files to a GitHub repository.
2. Link the repository to your hosting provider.
3. No build step or build command is required. Just set the publish directory to the root (`/`).

## Local Usage
Simply open `index.html` in any web browser to run the application locally.
